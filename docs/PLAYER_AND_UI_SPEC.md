# StrmAction iOS 播放器与交互设计规范（Player & UI Spec）

本文档定义 **StrmAction iOS Companion** 播放界面的视觉系统、交互手势、抽屉面板设计以及 iOS 原生特性的实现规范。

参考实现：Android 伴侣端 `companion/app/src/main/java/top/strmaction/companion/PlayerActivity.kt` 及 `player/` 目录。两端保持同一套设计语言（主强调色、控件自动隐藏 4.5 秒、手势分区、三层缓冲进度条）。

---

## 0. 代码结构

播放器 UI 已从单体 `PlayerView.swift` 拆分为分层结构，**新增文件无需任何工程配置**（XcodeGen 递归扫描 `Sources/`）：

| 文件 | 职责 |
|---|---|
| `Player/PlayerUIKit.swift` | 设计令牌 `PlayerTheme`、形状 `LeadingRoundedRectangle`、`SystemOrientation`、`PlayerTimeFormat`、`PlayerIconButton` / `PlayerPillButton` / `PlayerChromeGradient` |
| `Player/PlayerUIController.swift` | **UI 状态机**：控件显隐、锁定、全屏、面板、居中浮层、手势仲裁、自动隐藏定时器 |
| `Player/PlayerControls.swift` | `PlayerTopBar` / `PlayerBottomBar` / `PlayerCenterButton` / `PlayerLockEntryButton` / `PlayerLockButton` |
| `Player/PlayerOverlays.swift` | `PlayerCenterBadgeView`（居中浮层）/ `PlayerSpeedBadgeView` / `PlayerBufferingView` / `PlayerErrorOverlay` / `PlayerAutoNextOverlay` |
| `Player/PlayerDrawerView.swift` | `PlayerDrawerView`（抽屉外壳）+ 行组件 + `PlayerDrawerContent`（菜单/选集/倍速/字幕内容） |
| `Player/BufferedSeekBar.swift` | 三层缓冲进度条 |
| `Player/PlayerView.swift` | 编排层：ZStack 层级、生命周期、进度上报、远程控制 |
| `Player/VideoPlayerAdapter.swift` | `VideoPlayerController`（KSPlayer / AVPlayer 双内核）与渲染视图 |

**关键约束**：所有瞬时 UI 状态与定时器集中在 `PlayerUIController`，视图层只做渲染。这是「拖动进度条时控件自动消失」这类竞态不复发的根本保证。

## 2. 播放器主界面布局

### 2.1 ZStack 层级（顺序即绘制顺序，**不可随意调整**）

```text
1. 视频画面 (VideoSurfaceView)
2. 手势层      ← 必须在控件层之下！否则全屏 Color.clear 会吞掉所有按钮点击
3. 控件层      ← 顶/底渐变 + 顶栏 + 中心键 + 底栏 + 锁定入口
4. 亮度遮罩    ← 盖住画面与控件，不接收触摸
5. 瞬时浮层    ← 顶部倍速泡、居中反馈泡、缓冲指示
6. 解锁按钮    ← 仅锁定态，压在亮度遮罩之上
7. 自动连播浮层
8. 播放错误浮层
9. 功能抽屉    ← 最上层
```

### 2.2 界面布局

```text
┌────────────────────────────────────────────────────────┐
│ [←] 剧集标题                          [比例][画中画][⋯] │  ← TopBar
│                                          [🔓]          │  ← 锁定入口(右侧居中)
│                         [ ▶ ]                          │  ← CenterPlayButton
│                                                        │
│              ┌────────────────┐                        │
│              │ ☀ 亮度   62%   │  ← 居中浮层（不跟手）   │
│              └────────────────┘                        │
│ ────────────────────────●───────────────────────────── │  ← BufferedSeekBar
│ [▶/⏸] [⏮] [⏭]  03:15 / 48:20        [选集][倍速][⛶]   │  ← BottomBar
└────────────────────────────────────────────────────────┘
```

### 2.3 顶部栏 (TopBar)
* **返回键**：抽屉打开时先关抽屉，否则退出播放并补传进度。
* **标题区**：单行截断，优先 `{系列名称} {单集标题}`。
* **右侧**：画面比例切换 → 画中画（仅在设备支持时显示）→ 更多设置（打开 `.menu` 抽屉）。

### 2.4 底部栏 (BottomBar)
* **三层缓冲进度条**：轨道 4pt（拖动时 6pt），滑块为金橙外环 + 白芯同心双圆，触摸区 28pt 且随内容撑开。
* **左排**：播放/暂停、上一集、下一集、时间文本。
* **右排**：「选集」胶囊、「倍速」胶囊（1.0x 时显示「倍速」）、**全屏按钮**。

### 2.5 全屏切换
* 底栏最右侧常驻全屏按钮，图标 `arrow.up.left.and.arrow.down.right` / `arrow.down.forward.and.arrow.up.backward`。
* 进入全屏：请求横屏（iPad 允许全部方向）+ `.persistentSystemOverlays(.hidden)` 收起状态栏与 Home Indicator。
* 切换后强制呼出控件并重置 4.5 秒倒计时，避免旋转过程中控件处于不可见状态。
* 退出播放时恢复 `UIInterfaceOrientationMask.all`。

### 2.6 屏幕锁定
* **锁定入口**：随控件一起显隐，悬浮在右侧垂直居中，38pt 圆形半透明底。
* 锁定后：关闭抽屉、隐藏全部控件、**暂停播放**。
* **解锁按钮**：锁定态唯一可见控件，44pt 圆形；无操作 **3 秒**后自动隐藏。
* 锁定态下单击画面：第一次唤出解锁按钮，再次单击直接收起。
* 锁定态除单击外所有手势失效；点解锁按钮恢复控件与播放。

## 3. 功能抽屉

彻底摒弃系统级弹窗，所有二级菜单以**右侧抽屉**形式展现：横屏 40% 屏宽，竖屏 70%（不小于 300pt）。

### 3.1 视觉规范（相对旧版的三处结构性修正）

| 问题 | 旧版 | 新版 |
|---|---|---|
| **整个画面变暗** | 全屏 `53%` 纯黑遮罩 | **方向性渐变**：左 `10%` → 中 `20%` → 右 `55%`，视频主体基本保持可见 |
| **边界不清晰** | 面板 `97%` 不透明 + 零阴影 | **实色面板 + 左侧 26pt 投影 + 1pt 发丝描边** |
| **形态不连续** | 圆角方向与屏幕边缘不贴合 | **仅朝向视频的左侧带 18pt 圆角**，贴屏幕右缘为直角 |

* 点击遮罩任意处收起；子面板有返回箭头，顶级面板只有关闭按钮。
* 行组件统一 14pt 内边距、12pt 圆角、8pt 条目间距；选中态为 `#E8B06A` 20% 底 + 金橙加粗文字 + `✓`。
* 全部使用 SF Symbols（`captions.bubble` / `speedometer` / `internaldrive` / `forward.end` / `arrow.up.forward.app` / `doc.on.doc`），**不使用 emoji**。

### 3.2 主菜单（`.menu`）
`字幕` → · `播放速度` → · `画面比例`（点击即切换，副标题实时反映） · `播放缓存`（信息行） · `下一集`（有下一集时显示） · `用外部播放器打开` · `复制视频直链` · `证书信任`（打开指纹管理面板，副标题显示已固定服务器数量）

> 播放通道不再可切换：媒体字节只经 FFmpeg 自有 HTTP/TLS 栈直连源站，
> 自签名由证书指纹固定解决，没有代理、没有备用通道。

### 3.3 子面板
* **选集 (`.episodes`)**：当前集前置 `▶` 并高亮，其余正常；点击其它集立即切换。
* **倍速 (`.speed`)**：`0.5x / 0.75x / 1.0x / 1.25x / 1.5x / 2.0x / 3.0x`，独立配置**长按加速倍速**（`1.5x / 2.0x / 2.5x / 3.0x`，默认 `2.0x`，持久化到 `UserDefaults` 的 `long_press_speed`）。
* **字幕 (`.subtitles`)**：首项「关闭字幕」，随后是服务端下发的外挂字幕；选中后下载并外挂加载。

> 抽屉内的状态变化**直接反映在行内**，不弹 Toast（面板会遮挡居中浮层）。

## 4. 手势交互系统

| 手势 | 判定 | 效果 | 反馈 |
|---|---|---|---|
| **单击** | 屏幕任意区域 | 唤起/隐藏控件 | 0.2s 淡入淡出 |
| **双击左 35%** | 左 1/3 | 快退 10 秒 | 居中浮层 `快退 10 秒` |
| **双击右 35%** | 右 1/3 | 快进 10 秒 | 居中浮层 `快进 10 秒` |
| **双击中央 30%** | 中 1/3 | 播放/暂停 | 中心按键切换 |
| **长按 ≥0.35s** | 屏幕任意区域 | 触觉反馈 + 临时提速到长按倍速，松手恢复 | 顶部泡 `2.0x 倍速播放中` |
| **横向拖动** | 越界 14pt 且 `\|dx\| > \|dy\|` | 进度预瞄（整屏映射 `min(时长, 3分钟)`） | 居中浮层 `03:45 / 45:00 (+30s) · 已缓冲/缓冲中` |
| **纵向拖动（左半屏）** | 越界 14pt 且 `\|dy\| ≥ \|dx\|` | 调亮度（0.02~1.0） | 居中浮层 `☀ 亮度 62%` + 细进度条 |
| **纵向拖动（右半屏）** | 同上 | 调播放器音量（0~1） | 居中浮层 `🔊 音量 50%` + 细进度条 |

### 4.1 三条硬性约束

1. **反馈浮层一律居中**，绝不跟随手指位置（旧版放在屏幕左右两侧 `x=60`/`width-60`，视觉上像贴着手指）。
2. **手势模式一次性锁定**：首次越过 14pt 死区时判定为进度/亮度/音量之一，直到手指抬起不再改判，杜绝滑动中途跳变。
3. **单击与双击用 `ExclusiveGesture(SpatialTapGesture(2), SpatialTapGesture(1))`**，双击优先、单击等判定窗口结束再触发。这是双击「点了没反应」的根因修复（旧版同时挂了 `TapGesture` 与 `SpatialTapGesture`，互相抢事件）。

### 4.2 亮度实现
iOS **没有** per-window 亮度 API（Android 的 `window.attributes.screenBrightness`）。改用**全屏压暗遮罩**：

* 遮罩不透明度 = `(1 - brightness) × 0.75`，盖在画面与控件之上、浮层之下；
* 退出播放页自动还原，**不污染系统设置**；
* 初始值取 `UIScreen.main.brightness`，用户一上手就知道原来是多少。

音量走 `AVPlayer` / KSPlayer 的播放器音量，同样不改动系统音量。

### 4.3 自动隐藏（4.5 秒）
同时满足以下**全部**条件才会计时，缺一即取消：
`未锁定` && `控件可见` && `抽屉未打开` && `未拖动进度条` && `未进行进度手势` && `正在播放`

* **拖动进度条**：进入拖动立刻 `cancelAutoHide()`，松手才 `scheduleAutoHide()`——**控件不会在拖到一半时消失**。
* **进度手势**：同上，`gestureMode == .scrub` 期间不计时。
* **暂停**：不自动隐藏。
* 重置触发的操作：单击、播放/暂停、拖动松手、seek、改倍速、全屏切换、抽屉关闭、播放状态变化。

## 5. iOS 专属功能规范

### 5.1 原生画中画 (PiP)
* 通过 KSPlayer 的 `pipController` 实现；`isPiPAvailable` 为真时才显示按钮。
* 顶部栏按钮进入/退出，进度与远程控制同步。

### 5.2 锁屏控制与媒体中心
* `AVAudioSession` 配置 `.playback` + `.moviePlayback`，`UIBackgroundModes` 含 `audio`。
* `MPNowPlayingInfoCenter` 写入标题、艺术家、已播放时间、总时长、播放速率。
* 响应 `MPRemoteCommandCenter`：`play` / `pause` / `togglePlayPause` / `skipForward(10s)` / `skipBackward(10s)` / `changePlaybackPosition`。
* 由 App 统一注册（`options.registerRemoteControll = false`），避免与 KSPlayer 重复响应。

### 5.3 字幕渲染
外挂字幕经 `PlayApi` 下载为临时文件后交给 KSPlayer 字幕引擎；同时把当前字幕文本以原生控件渲染在底部上方（换集/重试后自动重新挂载）。

## 6. 超时与网盘异常处理

1. **15 秒超时保护**：未能读取到首帧且无错误时，弹出「连接网盘超时」警示，提供**重试连接 / 复制直链 / 用外部播放器打开**三个出口。
2. **缓冲指示**：首帧到达前显示居中 `正在缓冲…`（金橙 `ProgressView`）。
3. **播完连播过渡**：播放完毕后展示 3 秒倒计时浮层「即将播放下一集」，可取消或立即播放。
4. **播放错误浮层**：整屏 86% 黑 + 实色卡片，提供重试与关闭。
