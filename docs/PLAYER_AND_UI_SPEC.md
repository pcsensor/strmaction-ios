# StrmAction iOS 播放器与交互设计规范（Player & UI Spec）

本文档定义了 **StrmAction iOS Companion** 播放界面的视觉系统、交互手势、40% 抽屉设计以及 iOS 原生特性的实现规范，保证与 Android 伴侣端的设计语言完全一致。

---

## 1. 视觉系统与主题配色

整个 App 采用现代主流流媒体客户端的暗黑风格，主色调与高亮色定义如下：

| 元素 | 色值 / 规范 | 说明 |
|---|---|---|
| **底色 / 背景色** | `#07080A` | 极深灰黑，保证 OLED 屏幕纯黑观感 |
| **主强调色 (Accent)** | `#E8B06A` | 暖金黄，用于高亮当前播放剧集、进度条高能段、主要操作按钮 |
| **次强调色** | `#5C6678` / `#8A93A5` | 中灰蓝，用于副标题、次要文字、未选中状态 |
| **纯白文字** | `#FFFFFF` | 标题、当前播放时间、激活图标 |
| **遮罩透明度** | `rgba(0, 0, 0, 0.65)` | 顶部/底部渐变栏以及抽屉左侧遮罩底色 |
| **抽屉背景** | `rgba(20, 22, 28, 0.95)` | 暗黑磨砂毛玻璃材质（推荐 UIBlurEffect.Style.systemMaterialDark） |

## 2. 播放器主界面布局

播放界面由底层渲染视图与上层悬浮控制层叠加组成：

```text
┌────────────────────────────────────────────────────────┐
│ [←] 剧集标题 (S01E01 消失的威尔·拜尔斯)      [画中画] [更多⚙] │  <- TopBar
│                                                        │
│                                                        │
│                         [ ▶ ]                          │  <- CenterPlayButton
│                                                        │
│                                                        │
│ ────────────────────────●───────────────────────────── │  <- BufferedSeekBar
│ [▶/⏸] [⏮] [⏭]  03:15 / 48:20              [选集] [倍速] [⛶]│  <- BottomBar
└────────────────────────────────────────────────────────┘
```

### 2.1 顶部栏 (TopBar)
* **左侧返回键**：点击直接退出播放，返回 Web 容器，并补传一次当前播放进度。
* **标题区**：单行文本，超出自动截断。格式优先展示：`{系列名称} {季集编号} {单集标题}`。
* **右侧操作区**：
  * **画中画按钮 (PiP)**：点击主动将当前播放缩小为 iOS 悬浮画中画窗口。
  * **更多设置按钮 (⚙)**：点击从屏幕右侧滑出「更多设置抽屉」（包含音轨、字幕切换）。

### 2.2 屏幕中央大按钮 (CenterPlayButton)
* 直径 64pt 的圆形半透明按键，图标为纯白色的现代矢量播放/暂停图标。
* 状态随播放状态实时切换；在控件处于隐藏状态时，中央按键随之淡出。

### 2.3 底部栏 (BottomBar)
* **精致三层缓冲进度条 (BufferedSeekBar)**：
  1. **底层（未缓冲）**：高 3pt，颜色为 `rgba(255, 255, 255, 0.2)`；
  2. **中层（已缓冲）**：高 3pt，颜色为 `rgba(255, 255, 255, 0.5)`，反映视频已加载入内存的进度；
  3. **顶层（已播放）**：高 3pt，颜色为 `#E8B06A`（暖金色），末端带 10pt 的圆形拖拽滑块；
  4. **触摸响应区**：垂直判定区域扩展至 36pt，确保手指轻松触碰。
* **下排控制项**：
  * **左侧**：播放/暂停切换键、上一集按键（无上一集时置灰）、下一集按键（无下一集时置灰）、播放时间文本（`05:20 / 45:00`）。
  * **右侧**：
    * **「选集」按钮**：点击唤起 40% 右侧选集抽屉。
    * **「倍速」标签**：显示当前倍速（如 `1.0x`），点击唤起 40% 右侧倍速抽屉。
    * **「全屏/横竖屏锁定」按键**：切换横屏或跟随重力感应。

## 3. 40% 右侧侧滑抽屉交互（核心特色）

彻底摒弃传统的系统级弹窗，所有二级菜单均以 **占屏幕右侧 40% 宽度的侧滑抽屉** 形式展现（左侧 60% 为半透明遮罩，点击左侧遮罩区域即刻平滑收回抽屉）。

```text
┌───────────────────────────────────────┬──────────────┐
│                                       │ 选集         │
│                                       ├──────────────┤
│                                       │ [▶] 01 消失的 │
│                                       │    威尔·拜尔斯 │
│                                       │              │
│        (点击此处收起抽屉 60%)           │ [✓] 02 枫树街 │
│                                       │    上的怪人   │
│                                       │              │
│                                       │ [ ] 03 霍利， │
│                                       │    愉快的... │
└───────────────────────────────────────┴──────────────┘
```

### 3.1 选集抽屉 (Episodes Drawer)
* 展示服务器下发的 `playlist` 列表。
* **卡片项状态规范**：
  * **当前正在播放**：外框或标签高亮 `#E8B06A`，前置标明 `▶` 图标；
  * **已看集数 (`watched: true`)**：右侧展示勾选标志 `✓`；
  * **点击切换**：点击其它集数，关闭抽屉并立即调用该集的 `itemId` 重新触发播放链路。

### 3.2 倍速抽屉 (Speed Drawer)
* 展示预设速率：`0.5x`、`0.75x`、`1.0x`、`1.25x`、`1.5x`、`2.0x`、`3.0x`。
* 支持单独配置 **「长按快捷倍速」**（可在 `1.5x` / `2.0x` / `2.5x` / `3.0x` 中选择，默认 `2.0x`），配置即时持久化到 `UserDefaults`。

### 3.3 更多设置抽屉 (More Settings Drawer)
* **音轨切换**：读取媒体流中的音频轨列表（如普通话、原声 Dolby Atmos 等），支持点击切换。
* **字幕切换**：
  * 列表首项为「关闭字幕」；
  * 支持内置内嵌字幕轨；
  * 支持服务器下发的 `subtitles` 列表（外挂 ASS/SRT）；选中外挂字幕后，播放器下载字幕文本并通过字幕引擎外挂加载。
* **外部播放器跳转**：底部保留「用外部播放器打开（Infuse / VLC）」按钮作为兜底。

## 4. 手势交互系统（主流体验对齐）

| 手势类型 | 判定区域 | 交互效果 | 界面提示反馈 |
|---|---|---|---|
| **单击 (Tap)** | 屏幕任意区域 | 唤起/隐藏 TopBar 与 BottomBar（若未操作，4.5 秒后自动淡出消失） | 控件平滑透明度渐变 |
| **双击左侧** | 屏幕左侧 35% | 当前播放位置**快退 10 秒** | 屏幕中央浮现 `⏪ 快退 10 秒` 提示泡 |
| **双击右侧** | 屏幕右侧 35% | 当前播放位置**快进 10 秒** | 屏幕中央浮现 `⏩ 快进 10 秒` 提示泡 |
| **双击中央** | 屏幕中央 30% | 切换 播放 / 暂停 | 中央大按键切换状态 |
| **长按 (Long Press)** | 屏幕任意区域 | 1. 触发 iPhone **Taptic Engine 触觉震动反馈**（`UIImpactFeedbackGenerator(style: .medium)`）<br>2. 临时将倍速提升至预设的「长按倍速」（默认 2.0x）<br>3. 手指松开时恢复原播放速度 | 屏幕顶部正中央浮现金色提示：<br>`▶▶ 2.0x 极速播放中` |
| **垂直滑动（左半屏）** | 屏幕左侧 50% | 调节当前屏幕亮度 | 侧边浮现亮度滑块条 |
| **垂直滑动（右半屏）** | 屏幕右侧 50% | 调节系统音频音量 | 侧边浮现音量滑块条 |
| **水平滑动** | 屏幕中央区域 | 快进/快退手势预拖拽 | 屏幕中心展示目标时间与变化量（如 `+00:30 (12:40)`） |

## 5. iOS 专属功能规范

### 5.1 原生画中画 (Picture-in-Picture)
* 使用 iOS 原生 `AVPictureInPictureController`（针对 Metal 渲染图层可使用 `AVPictureInPictureVideoCallViewController` 或绑定专用 SampleBufferDisplayLayer）。
* 在 App 切入后台（`applicationDidEnterBackground` 或 `sceneDidEnterBackground`）且视频正在播放时，**自动开启画中画**，实现无缝边看边聊。

### 5.2 锁屏控制与媒体中心 (MPNowPlayingInfoCenter)
* 配置 `AVAudioSession.sharedInstance().setCategory(.playback, mode: .moviePlayback)`，声明 `UIBackgroundModes` 包含 `audio`。
* 播放开始时，向 `MPNowPlayingInfoCenter.default().nowPlayingInfo` 写入：
  * `MPMediaItemPropertyTitle`: 视频标题
  * `MPMediaItemPropertyArtist`: 系列剧名或 StrmAction
  * `MPNowPlayingInfoPropertyElapsedPlaybackTime`: 当前进度（秒）
  * `MPMediaItemPropertyPlaybackDuration`: 总时长（秒）
  * `MPNowPlayingInfoPropertyPlaybackRate`: 当前播放倍速（播放中为 1.0 或设置倍速，暂停为 0.0）
* 响应 `MPRemoteCommandCenter` 的 `playCommand`、`pauseCommand`、`skipForwardCommand(10s)`、`skipBackwardCommand(10s)`、`changePlaybackPositionCommand`。

## 6. 超时与网盘异常处理

针对网盘 CDN 的网络波动（如 302 跳转超时、百度防盗链拦截等）：

1. **15 秒超时保护**：从向播放内核发起播放请求起，若连续 15 秒未能读取到首帧（依然处于 Buffering 状态），自动弹出友好警示弹窗：
   * 提示文案：「连接网盘超时，可能因防盗链拦截或网络阻塞」。
   * 提供三个操作按钮：
     * **「重试连接」**（重新请求直链播放）；
     * **「复制直链」**（复制解密后的直链至系统剪贴板）；
     * **「用外部播放器打开」**（尝试通过 URL Scheme 拉起 Infuse / VLC）。
2. **播完连播过渡**：当当前视频播放完毕（`position >= duration`），自动展示 3 秒倒计时浮层：「即将播放下一集: S01E02」，倒计时结束后自动调用 `next_item_id` 无缝载入。
